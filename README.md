# 学习守护 · Android 项目

孩子玩游戏 / 刷短视频满设定时长 → 弹出无法关闭的全屏答题窗 → 答对才能继续使用。

这是**可直接运行的完整项目骨架**，不是演示代码。功能逻辑已经全部实现，面板样式按你的要求保持了最基础的样子，方便你后续自己调整。

## 一、先说明一件事

这份代码**已经过资源引用交叉校验**（`tools/check_res.py` 扫描全部 40 个文件，所有 `R.string / R.drawable / R.color / R.style / R.array / ?attr` 引用都能对应到定义，零缺失）。功能逻辑完整、可独立运行，不依赖任何外部题库文件——题目由 Kotlin 在运行时按固定种子实时生成。

编译本身在**云端**完成（见下面的「方法零」），本机不需要装 JDK / Android SDK。如果你更想在本机编译，把整个 `KidsGuard` 文件夹用 Android Studio 打开即可（见第三节）。

## 方法零：线上生成 APK（推荐，最省事，不用装任何开发环境）

不想在自己电脑上装 Android Studio？可以用 **GitHub Actions 云端编译**：代码传上去，GitHub 的服务器自动下载 JDK / Android SDK / Gradle 并完成编译，最后给你一个可直接下载安装的 `app-debug.apk`。**全程不需要你装任何东西，也不需要本机有 JDK。**

项目里已经放好了构建脚本：`.github/workflows/build-apk.yml`。

### 步骤（第一次约 5–10 分钟，之后每次推代码自动重新编译）

1. 注册一个免费的 GitHub 账号：<https://github.com/join>
2. 新建一个仓库（Repository），名字随便起，比如 `kidsguard`，**选 Public 或 Private 都行**
3. 把 `KidsGuard` 整个文件夹上传进这个仓库（最简单：在仓库页面点 **Add file → Upload files**，把文件夹里的所有内容拖进去；或装 GitHub Desktop 拖文件夹）
4. 上传完成后，点仓库顶部的 **Actions** 标签 → 会看到名为 **Build KidsGuard APK** 的工作流在跑
5. 等它变绿（✅），点进去 → 在 **Artifacts** 里下载 **KidsGuard-debug-apk**（里面就是 `app-debug.apk`）
6. 把 `app-debug.apk` 传到手机上安装即可

> 小提示：Actions 第一次跑可能因为「需要授权工作流」而停在黄色状态，点一下 **I understand… / Run workflow** 允许即可。
> 想重新编译？改完代码再推一次，会自动重新跑。

## 二、准备环境（只需做一次）

### 1. 安装 Android Studio

下载地址：<https://developer.android.com/studio>

- 安装包约 1GB，装完加上 SDK 约 5–8GB，确保 C 盘有空间
- 安装时一路「Next」即可，全部用默认选项
- 第一次启动会下载 Android SDK，**保持联网，耐心等**，可能需要 20–40 分钟

### 2. 准备一部 Android 手机

要求：**Android 8.0 以上**，并且最好是**孩子专用的设备**（不要装在家长自己常用的手机上，否则无法做设备级管控）。

---

## 三、打开项目

1. 打开 Android Studio
2. 首页点 **Open**（不是 New Project）
3. 选择 `KidsGuard` 这个文件夹（**注意：选文件夹本身，不要选里面的 app**）
4. 点 OK，Android Studio 会自动识别并开始同步 Gradle
5. 第一次同步会下载依赖，看底部进度条，等它跑完（可能要 10 分钟以上）
6. 如果弹窗提示缺少 SDK 或要装 Gradle，一律点「Install」/「OK」

同步完成后，左下角没有红色报错就说明环境正常。

---

## 四、装到手机上

### 方法一：USB 线直接装（推荐，最省事）

1. 手机进「设置 → 关于手机」，**连续点「版本号」7 次**，直到提示已进入开发者模式
2. 回设置，进「系统 → 开发者选项」，打开 **USB 调试**
3. 用数据线连电脑，手机上点「允许 USB 调试」
4. Android Studio 顶部会显示你的手机型号，点右边的绿色三角 **Run** 按钮
5. 手机上会提示安装，允许即可

> 华为、小米、OPPO、vivo 的开发者选项位置略有差异，找不到就直接搜「XX 手机 打开 USB 调试」。

### 方法二：打包成 APK

菜单 **Build → Build Bundle(s)/APK(s) → Build APK(s)**，生成的 APK 在
`app/build/outputs/apk/debug/app-debug.apk`，传给手机安装即可。

## 五、首次配置（4 步，约 3 分钟）

1. **开启使用情况访问权限**
   打开应用 → 点「前往开启」→ 在系统设置里找到「学习守护」→ 打开开关 → 返回

   > 这个权限比较特殊，Android 不允许 App 自己弹窗申请，必须手动开一次。这是整个应用的核心，不开就什么都监控不到。

2. **启动监控**
   回到应用，点「启动监控」。系统会提示是否允许后台运行，选**允许 / 不优化**。

   > 不加电池优化白名单，系统很可能在后台把监控杀掉，导致时灵时不灵。

3. **设置应用归类（最重要的一步）**
   主界面 → 家长模式 → 输入初始密码 **1234** → 管理应用归类

   - 切到「最近使用」，孩子玩过的应用都在里面，一眼就能认出来
   - 该拦的点 **受限**，学习用的点 **学习**
   - **只有「受限」的应用才会弹窗**，其余一律不拦

   建议顺手确认两件事：
   - 网课软件（钉钉、腾讯会议）一定要标成**学习**
   - **浏览器别标成学习**——孩子会用浏览器刷视频、玩网页游戏，它是最容易被漏掉的娱乐入口

4. **激活设备管理器（强烈建议）**
   家长模式 → 激活设备管理器。激活后孩子**无法直接卸载**，也不能在设置里一键强停。

   > 不做这一步，孩子进设置就能把应用卸掉，前面全白搭。

配置完成，可以让孩子拿去用了。

## 七、改面板布局（你要的这部分）

布局文件各自对应一个界面：

| 文件 | 界面对应 |
|---|---|
| `res/layout/activity_main.xml` | 主界面（学习中心）：问候、主题切换、守护额度、年级、六大模块入口 |
| `res/layout/activity_lock.xml` | **全屏答题锁**，孩子被拦时看到的界面（四选一 / 填空） |
| `res/layout/activity_parent.xml` | 家长模式：密码 + 三段式规则设置 + 应用归类入口 |
| `res/layout/activity_practice.xml` | 分模块练习 / 运动打卡 |
| `res/layout/activity_app_list.xml` | 应用归类列表 |
| `res/layout/item_app.xml` | 归类列表里的单行（应用名 + 三个按钮） |

### 三条规矩

1. **不要删除任何带 `android:id` 的控件**——删了 Kotlin 代码就编译不过。想隐藏某块内容，把它的 `android:visibility` 改成 `gone` 即可。
2. **文字大小、颜色、间距、排列方式随便改**，不影响功能。
3. **`activity_lock.xml` 里改动要谨慎**：答题锁的有效性依赖全屏和无标题设置，这些在 `themes.xml` 的 `Theme.KidsGuard.Lock` 里，别把 `windowFullscreen` 删掉。

### 常见改法

- **换配色**：改 `res/values/colors.xml`，里面的注释说明了每个颜色的用途
- **改文案**：改 `res/values/strings.xml`
- **调字号**：直接在布局文件里改 `android:textSize`
- **想加背景图**：把图片放进 `res/drawable/`，然后在布局根元素上加 `android:background="@drawable/你的图片名"`

改完点 Android Studio 顶部的小锤子 **Make Project**，再点 Run 就能看到效果。

## 八、默认参数

学习守护采用**三段式拦截规则**，全部可在家长模式里调整：

| 阶段 | 触发条件 | 行为 | 默认值（家长模式可改） |
|---|---|---|---|
| 额度内 | 当日娱乐 ≤ 60 分钟 | 不弹窗，自由使用 | 每日额度 **60 分钟** |
| 第一段 | 超额后 | 每 **10 分钟**弹一次答题窗，连续答对 **3 题**换 **10 分钟** | 间隔 10 分 / 连对 3 题 / 奖励 10 分 |
| 第二段 | 累计用到 **90 分钟**（即超额 30 分）后 | 收紧为每 **5 分钟**弹一次 | 收紧阈值 90 分 / 间隔 5 分 |

> 出题范围：语文 / 数学 / 英语 / 音乐 / 运动 / 脑筋急转弯 六个模块，每个模块分小学一~三年级。
> 数学 / 语文 / 英语 由算法按年级从简单到困难实时生成题目；音乐、脑筋急转弯为内置精选，运动为动作打卡。
> 家长密码默认 **1234**（请务必在家长模式里修改）。

## 九、已知的限制（技术边界，不是 bug）

1. **按 Home 键仍能退出弹窗。**
   普通 Android 应用屏蔽不了 Home 键，只有把设备激活成「设备所有者」才能做到，那需要通过电脑跑 ADB 命令或扫码预置，门槛较高。对 6–9 岁的孩子，现有的拦返回键 + 全屏覆盖通常已经够用。

2. **孩子进设置页可以强行停用。**
   激活设备管理器后能挡住卸载和强停，但孩子仍可以在设置里手动「取消激活设备管理器」。需要在家长模式的引导下把这一步也保护起来，或者由家长定期检查。

3. **iOS / iPad 上做不了这件事。**
   苹果不允许第三方 App 弹自定义全屏界面，这个玩法在 iPhone 和 iPad 上无法实现。

4. **改系统时间无效，但改日期会重置额度。**
   计时用的是设备开机时钟，改时间骗不过去；不过「今日额度」按日期归零，把日期往后调一天额度会重置。如果要堵这个口子，需要联网校时，留作后续版本。

## 十、出问题先看这里

| 现象 | 原因与处理 |
|---|---|
| 主界面一直提示要开权限 | 使用情况访问权限没开。部分手机（小米、华为）需要在「权限 → 特殊权限设置」里找 |
| 开了监控但从不弹窗 | 应用归类里没有把任何应用标成「受限」，去家长模式检查 |
| 弹窗能按返回键退出 | 正常现象，代码只拦了返回键和后退手势，Home 键拦不住（见上） |
| 过一会儿就不监控了 | 电池优化没关，或者被系统清理了。重新进应用点一次启动监控，并确认已加入白名单 |
| 提示「编译错误」 | 把红色报错信息复制出来问 AI 或开发，通常是版本差异，改动很小 |
| 应用列表是空的 | 使用情况访问权限没开，或者 Android 11+ 的 queries 声明被误删（在 `AndroidManifest.xml` 里） |

## 奖励制度（⭐ 星星）

用 ⭐ 星星做正向激励，把「管控」变成游戏化的成长记录：孩子答题 / 学习 → 赚星星 → 换奖励。

**怎么赚星星：**
- 练习模式每答对 1 题：**+1 ⭐**
- 全屏答题锁每答对 1 题：**+1 ⭐**，连续答通关额外 **+5 ⭐**
- 运动打卡每完成 1 次：**+2 ⭐**

**星星能换什么（主界面 → 奖励小屋）：**

| 奖励 | 消耗 | 说明 |
|---|---|---|
| +10 分钟娱乐时间 | 10 ⭐ | 直接追加当天娱乐额度 |
| 免一次弹窗 | 15 ⭐ | 下次被拦时自动放行一次 |
| 实物小奖励（找家长） | 30 ⭐ | 需家长输入密码确认，避免孩子自己乱换 |

星星跨天不清零，是长期成长记录。奖励成本在 `RewardActivity.kt` 顶部的 `COST_*` 常量里，可随时调整。
相关文件：`ui/RewardActivity.kt`、`res/layout/activity_reward.xml`、`data/PrefsManager.kt`（stars / freePasses）。

## 十一、接下来可以做的事

按优先级排：

1. **先别加功能，拿给孩子试一周。** 观察他多久能找到绕过方法，这决定后面值不值得投入。
2. **录入孩子真实的错题**（家长自定义题库）。这个功能目前的代码里数据层已经写好了（`QuestionRepository` 的 `addCustomQuestion`），只差一个录入界面。这是最值得优先补的功能——内置题孩子做多了会背答案，他自己的错题绕不过去。
3. **补上周报和薄弱知识点统计**。数据已经在答对/答错里记录了，缺的是展示界面。
4. **做时段规则**（作业时段、睡眠时段完全禁止娱乐）。逻辑不复杂，加一个时间段判断即可。
