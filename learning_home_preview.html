题库规模与实现路径

6 模块 × 3 年级 × 600 题 = 10,800 道。这个量不能靠手写，只能「结构化数据 + 生成器」。各模块可行性差别很大：

模块题量实现方式难度分档（各 200 题）可行性
数学1,800 算法参数化生成，题量实际无限 一年级：20 以内加减 → 100 以内 → 混合
二年级：表内乘法 → 两位数加减 → 应用题
三年级：万以内 → 多位数乘除 → 分数初步		 最容易
语文1,800 生字表 + 古诗库 + 词语库，模板生成 拼音选字 → 形近字/量词 → 古诗填空与理解 可做
英语1,800 1-3 年级词库（约 400 词）+ 模板生成 看图选词 → 中英互译 → 拼写与简单句型 可做
脑筋急转弯1,800 无法生成，只能收集 按年龄段打标分组 需人工
音乐1,800 常识题可生成；听音题需音频资源 乐器/节奏常识 → 儿歌歌词接龙 → 简谱识读 部分可做
运动1,800 建议改成动作打卡，不做纸笔题 跳绳/拍球/深蹲/平衡，按完成数量分级 形态不同
合计10,800算法可覆盖约 5,400 题；其余 5,400 题需要内容源或改形态
